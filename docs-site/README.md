# HackCafe Discovery Docs

Documentacao Docusaurus para discovery, estrategia de produto, dores do usuario e backlog rastreavel do HackCafe.

## Comandos

```powershell
pnpm install
pnpm run start
pnpm run typecheck
pnpm run build
```

## Fonte de verdade

Estas paginas preservam a cadeia exigida pelo projeto:

`hipotese -> evidencia -> decisao -> oportunidade -> requisito/story -> criterio de aceite -> metrica`

O conteudo e pesquisa de mesa. Antes de tratar qualquer recomendacao como orientacao agronomica real, valide com produtores, tecnicos ou agronomos.
